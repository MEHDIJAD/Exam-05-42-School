This repository contains my solutions for **Exam Rank 05** from the 42 School curriculum. The exam focuses on Object-Oriented Programming (OOP) in C++ and algorithmic problem-solving in C.

## 📁 Repository Structure

The project is organized into two levels, following the exam progression:

### [Level 01: C++ OOP](Level_01/)
- **[bigint](Level_01/bigint/):** Arbitrary precision unsigned integer. Supports addition and digit-shifting.
- **[polyset](Level_01/polyset/):** Polymorphic collection (bags/sets) using multiple inheritance.
- **[vec2](Level_01/vec2/):** 2D vector class with operator overloading.

### [Level 02: Algorithms](Level_02/)
- **[BSQ](Level_02/BSQ/):** Largest square finder (Dynamic Programming).
- **[gameOfLife](Level_02/gameOfLife/):** Conway's Game of Life simulation.

## 🔧 Getting Started

### Compilation
Navigate to any exercise and run:
```bash
make
```

### Example usage (Polyset)
```bash
cd Level_01/polyset
make
./polyset 1 7 9 0 23
```
